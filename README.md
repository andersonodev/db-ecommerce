
# Projeto de Banco de Dados - E-commerce

Este projeto implementa um banco de dados para um sistema de e-commerce, com funcionalidades como gestão de clientes (PF e PJ), produtos, pedidos, estoque e entregas.

## 📐 Modelagem
- Modelo lógico gerado via MySQL Workbench.
- Normalização em 3FN.
- Inclui relacionamentos n:n e herança (Cliente PF/PJ).

## 💾 Scripts
- `create_schema.sql`: criação das tabelas e constraints.
- `insert_data.sql`: dados de teste.
- `queries.sql`: consultas complexas com JOIN, HAVING, etc.

## 🛠️ Ferramentas
- MySQL 8.x
- Workbench para modelagem
